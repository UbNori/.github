## 🎓 윱놀이가 뭔가요?

**윱놀이**는 University의 **'윱'** 과 윷놀이의 **'놀이'** 를 합친 이름이에요.

- **말은 우리 학교 마스코트**: 학교를 대표해 다른 학교와 실시간 1:1로 맞붙어요.
- **말이 날 때마다 진급**: 첫 말이 나면 2학년, 둘째는 3학년, 셋째는 4학년. 네 말이 모두 나면 **졸업 = 승리**예요.
- **진짜 우리 학교 사람만**: 재학·휴학·졸업증명서를 제출하고 관리자 승인을 받아야 가입이 끝나요.
- **학교 랭킹**: 한 판 한 판이 학교 점수가 되어 주간·시즌 순위를 다퉈요.

## 🎲 대학 생활로 다시 쓴 윷놀이

| 윷 | 이동 | 윱놀이에서는 |
| :---: | :---: | --- |
| 도 | 1칸 | 출석 체크 |
| 개 | 2칸 | 과제 제출 |
| 걸 | 3칸 | 중간고사 통과 |
| 윷 | 4칸 + 한 번 더 | A+ |
| 모 | 5칸 + 한 번 더 | 장학금! |
| 빽도 | 뒤로 1칸 | 재수강 |

상대 말을 잡으면 그 말은 **휴학 처리**되어 처음으로 돌아가고, 내 말끼리 업으면 **스터디 그룹**이 되어 함께 움직여요.
